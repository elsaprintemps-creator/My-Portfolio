# My-Portfolio

Welcome to my portfolio. I hope you enjoy exploring my designs as much as I have enjoyed creating them. 👠✨

**Live site:** https://elsaprintemps-creator.github.io/My-Portfolio/

## About this repo

The whole site is one self-contained HTML file —
`elsa-printemps-portfolio (1).html` — with every style and image embedded
in it. There is no build step and nothing to install: open the file in any
browser to view it locally.

`index.html` simply redirects to that file, so the short link above works.

Fonts come from Google Fonts; everything else works offline.
